# Jaskinia v4: what changed after the recordings of 15–16 Oct 2026

The owner recorded five sessions with v3: four on a computer and one on a phone, 16 min 24 s together. Claude watched them
and wrote an independent review (C1). The review stays private, because it describes the owner's screen. This note keeps
only what changed in the product and why. Each item names the defect (F1–F14 in C1) and the check that now guards it in
`tools/jk4_test.mjs`.

Two things in the recordings changed what mattered most:

- **Jaskinia runs as a downloaded file.** On both devices the owner opened Jaskinia as a file, not inside claude.ai.
- **The phone is a full second place.** The longest recording was the phone. It went through every layout, so system
  gestures (Back, two fingers) matter as much as the desk.

## The truth about the data

- **The Pulse ends at the snapshot (F2).** Before, it ran to "today", so the days after the snapshot looked like days
  without commits. Now those days are a hatched strip with a title: "brak danych". The month names are no longer written
  by hand for 2026. Measured names never overlap: full names first, then short ones, then fewer.
- **The snapshot says how old it is in the top bar** ("zrzut · sprzed 2 dni"), not only in a tooltip.
- **Unknown is not zero (F3).** For a repository the API could not see, the wall card shows "? PR", and so do the agents'
  briefs and the curiosities in the statistics.
- **Every build names itself.** "v4" sits next to the name in the top bar. The build time and the place it runs in are in
  Settings → O Jaskini and in "Skąd są dane". The number comes from `src/jaskinia/version.txt`.

## Where Jaskinia runs (F1)

The place is detected when the page starts, not fixed at build time: a file (`file:` / `content:`), the owner's own
server (`--host web`), or claude.ai.

- **Games.** A file or the owner's server may show a game inside a window. A new setting, Ustawienia → Zachowanie → Gry,
  chooses where games open:
  - "Samo" (the default): a window on the desk, a new tab on the phone,
  - "W oknie": always in a window,
  - "W nowej karcie": always in a new tab.

  Under every game window there is a link that opens it in a new tab. Inside claude.ai games still open in a new tab, and
  the note in the game window says why.
- **Export** downloads a real file wherever the page may do that.
- **Tests** can pretend to be any of the three places with `window.__JASK_PLACE = 'plik' | 'web' | 'claude'`.

## The phone

- **Back closes the open sheet instead of leaving Jaskinia (F5).** One history entry of Jaskinia's own stands under the
  sheets. Code never takes it back, so a Back can never race a newly opened sheet and walk out of the page; the destruction
  test found exactly that race. After a sheet is closed by a tap, the next Back only steps off that entry.
- **An empty view of the wall says so (F6).** "Tu nic nie ma · pokaż wszystko" appears in the middle and brings the cards
  back. The window menu of the wall now has Pokaż wszystko, Nowa notatka, Ułóż… and Widok ściany…, because the phone hides
  them from the header.
- **Two fingers zoom the window, not the page (F7).** The pinch acts like Ctrl + wheel on the desk, and the page itself no
  longer pinch-zooms.

## The wall

- **Arranging never hides a card (F4).** After "Ułóż…", a note that would cover a card moves to a column on the right, in
  the same undo step, and a toast says so. "Rozsuń" now separates notes from cards too.
- **Findings speak one language (F10).**
  - The map, the wall and the cadastre all use amber for medium and red for serious.
  - With the Żar life colours, which run from yellow to red, the badges become rings on the ground colour, so they cannot
    be mistaken for a life colour.
- **Names are never broken inside a word (F12).** The font gets smaller first. A word that still does not fit ends with
  "…". A narrow card set by hand keeps its name: it is written upright, like a narrow parcel on the map.

## Windows

- **A floating window can be split (F11).** The new window floats beside it. Before, the split was refused with a toast.
- **"Zamknij puste okna" closes every "Pusty" window in one step (F13).** It is in the layouts menu and in the layout's
  own menu, and it can be undone.
- **The statistics windows no longer paint a text selection when dragged over (F9).**

## The feedback loop

The owner's feedback should cost minutes, not a night. Nothing leaves the device by itself.

- **"To mnie uwiera."** Open it with the flag button in the top bar, with Ctrl+., or from the main menu on a phone. The
  note is pinned to the second the button was pressed, together with the layout, the window, the project, the screen size
  and the version.
- **Dziennik (the log).** Jaskinia keeps the last 600 things that happened, with times: layout changes, switching,
  selection, menus and choices, toasts, errors, the start and the version.
- **"Paczka dla Claude'a" (the package)** is in Settings → Uwagi i paczka. It comes in two forms:
  - a JSON file with the version, the place, the device, the settings, the layouts, the notes and the log,
  - a short text to paste straight into a conversation.

  The text of the owner's notes is left out unless he ticks it. The folder of the file is never included (only its name),
  because a home folder carries a user name.

## Checks

- `tools/jk4_test.mjs` runs 40 checks for the above, on the desk, on a phone, and in each of the three places.
- `tools/jk2_chaos.mjs` now also opens window menus and presses Back while a sheet is open.
- All suites pass: 52 + 76 + 40, and the destruction runs with seeds 7, 13, 51, 99 and 2026.
- `tools/jk4_look.mjs` takes the screenshots for a human look: the bar, the Pulse, the wall after arranging, Żar, the
  phone wall, a floating split, English, and every theme.
